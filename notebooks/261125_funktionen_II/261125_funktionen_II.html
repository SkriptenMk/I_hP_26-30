11  Funktionen in Python: Vorgabewerte

Gerade bei repetitiven Berechnungen kommt es vor, dass einzelne Parameter einer Formel meistens, aber eben nicht immer, die gleichen Werte aufweisen.

Als Beispiel soll eine Funktion definiert werden, welche die Fläche eines Kreises berechnet. Standardmässig soll dabei \(\pi \approx 3.14\) gerechnet werden. Es soll aber möglich sein, für \(\pi\) einen anderen Wert zu verwenden.

import math

def kreisflaeche(radius: float, pi: float = 3.14) -> float:
    """Berechne die Fläche eines Kreises.

    Die Fläche wird nach der Formel A = pi * r**2 berechnet. Für die
    Kreiszahl wird standardmässig der Näherungswert 3.14 verwendet.
    Bei Bedarf kann ein genauerer Wert (z. B. ``math.pi``) oder eine
    andere Näherung (z. B. ``22 / 7``) übergeben werden.

    Parameters
    ----------
    radius : float
        Der Radius des Kreises. Der Wert sollte nicht negativ sein.
    pi : float, optional
        Der Wert, der für die Kreiszahl verwendet wird. Vorgabewert
        ist 3.14.

    Returns
    -------
    float
        Die Fläche des Kreises in der Quadrateinheit des Radius.

    Examples
    --------
    >>> kreisflaeche(2)
    12.56
    >>> kreisflaeche(2, pi=3.0)
    12.0
    """
    return pi * radius ** 2

Dadurch, dass in der Definition der Funktion kreisflaeche der Variable pi mit = 3.14 der Wert 3.14 zugewiesen wird, wird standardmässig dieser Wert verwendet. Wie alle Variablen, kann aber auch pi überschrieben werden.

print(kreisflaeche(2))                # 12.56            → Vorgabewert 3.14
print(kreisflaeche(2, math.pi))       # 12.566370614...  → exakter Wert
print(kreisflaeche(2, pi=22/7))       # 12.571...        → Näherungsbruch
12.56
12.566370614359172
12.571428571428571

11.1.1.3 Übung 3: Diagonalstrebe eines Gartentors

Formelsammlung S. 88 – Satz von Pythagoras

Ein rechteckiges Gartentor soll mit einer diagonalen Strebe verstärkt werden. Die Strebe bildet mit der Breite \(a\) und der Höhe \(b\) des Tors ein rechtwinkliges Dreieck; sie selbst ist die Hypotenuse \(c\):

\[a^2 + b^2 = c^2 \qquad\Rightarrow\qquad c = \sqrt{a^2 + b^2} .\]

Hinweis: Für die Quadratwurzel braucht es keine Bibliothek, denn \(\sqrt{x} = x^{0.5}\). In Python schreibt man x ** 0.5.

Aufgabe

  1. Definieren Sie eine Funktion hypotenuse(a, b) mit Typ-Hinweisen und Docstring.
  2. Das Tor ist 1.2 m breit und 1.6 m hoch. Wie lang muss die Strebe sein?
# Ihre Lösung
# Kontrolle
assert hypotenuse(3, 4) == 5
assert hypotenuse(5, 12) == 13
assert round(hypotenuse(1.2, 1.6), 6) == 2
print("Übung 3: alle Tests bestanden")

11.1.2 Teil B: Funktionen mit Vorgabewerten

In den folgenden drei Übungen werden die Funktionen aus Teil A um einen Parameter mit Vorgabewert erweitert. Wird das Argument beim Aufruf weggelassen, verhält sich die Funktion so, wie es im häufigsten Fall gewünscht ist.

11.1.2.1 Übung 4: Winkel in Grad oder Gon

Formelsammlung S. 86 – Winkelsumme

In der Schweizer Vermessung werden Winkel oft in Gon angegeben: Ein voller Kreis hat 400 gon, die Winkelsumme im Dreieck beträgt deshalb 200 gon statt 180°.

Aufgabe

  1. Erweitern Sie die Funktion aus Übung 1 zu dritter_winkel(alpha, beta, winkelsumme=180). Wird winkelsumme weggelassen, rechnet die Funktion wie bisher in Grad. Passen Sie auch den Docstring an.
  2. Ein Vermessungsteam misst \(\alpha = 62\) gon und \(\beta = 85\) gon. Wie gross ist \(\gamma\)?
  3. Warum ist 180 ein sinnvoller Vorgabewert?
# Ihre Lösung
# Kontrolle
assert dritter_winkel(50, 60) == 70              # Vorgabewert: Grad
assert dritter_winkel(50, 60, winkelsumme=200) == 90
assert dritter_winkel(50, 60, 200) == 90         # auch als Positionsargument
assert dritter_winkel(62, 85, winkelsumme=200) == 53
print("Übung 4: alle Tests bestanden")

Aufgabe

  1. Definieren Sie eine Funktion reale_flaeche(a, h_a, massstab=100). Die Längen werden in cm auf dem Plan übergeben, das Resultat soll die reale Fläche in m² sein. Verwenden Sie Ihre Funktion flaeche_dreieck aus Übung 2. Hinweis: 1 m² = 10 000 cm².
  2. Auf dem Plan ist die Giebelwand 9.6 cm breit und 4.5 cm hoch. Wie gross ist die reale Fläche? Wie gross wäre sie bei einem Plan im Massstab 1 : 50?
  3. Um welchen Faktor ändert sich die Fläche, wenn der Massstab halbiert wird (1 : 50 statt 1 : 100)? Begründen Sie mit den Ähnlichkeitssätzen.
# Ihre Lösung
# Kontrolle
assert reale_flaeche(6, 4) == 12
assert reale_flaeche(6, 4, massstab=50) == 3
assert round(reale_flaeche(9.6, 4.5), 2) == 21.6
assert round(reale_flaeche(9.6, 4.5, 50), 2) == 5.4
print("Übung 5: alle Tests bestanden")

11.1.2.3 Übung 6: Gerundete Strebenlänge

Formelsammlung S. 88 – Satz von Pythagoras

Hinweis: Die eingebaute Funktion round(zahl, stellen) rundet auf die gewünschte Anzahl Nachkommastellen, z. B. round(2.71828, 2) → 2.72.

Aufgabe

  1. Erweitern Sie die Funktion aus Übung 3 zu hypotenuse(a, b, nachkommastellen=3), die das Resultat rundet.
  2. Ein Tor ist 1.15 m breit und 1.8 m hoch. Geben Sie die Strebenlänge einmal mit dem Vorgabewert und einmal auf Zentimeter genau an.
# Ihre Lösung
# Kontrolle
assert hypotenuse(3, 4) == 5
assert hypotenuse(1, 1) == 1.414
assert hypotenuse(1, 1, nachkommastellen=1) == 1.4
assert hypotenuse(1.15, 1.8) == 2.136
assert hypotenuse(1.15, 1.8, 2) == 2.14
print("Übung 6: alle Tests bestanden")
